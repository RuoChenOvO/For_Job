1. 文件整理工具：按扩展名 / 关键词自动归类文件（实用、演示效果好）

> 原则：选小不选大，重点是完整走完「开发 → README → 上线 GitHub」全流程。

2. LeetCode 前三天会难受，正常现象，坚持两周就顺了。

3. 卡住 30 分钟就换任务或搜答案，不要死磕 —— 目标是把流程走通，不是完美主义。
