## 3. 项目定义：arXiv 论文问答助手

**为什么选它**
- 数据公开（arXiv API），无需清洗业务数据
- 天然可评测：问题 = "这篇论文的方法是什么/它的局限是什么"，答案要点可人工标注
- 面试官一看就懂，且和你"研究生看论文"的身份天然贴合

**最终形态**
1. 输入一个主题（如 `retrieval augmented generation`）→ 自动拉取 30 篇论文
2. 解析 PDF 正文 → 切分 → 向量化 → 建索引
3. 提问 → 检索 → 带引用回答（引用到 paper_id、页码或章节）
4. 配套评测：`python -m arxiv_qa.eval --config base.yaml` 一条命令出分数
5. 实验：查询改写 / 混合检索 / rerank 的消融对比

**技术栈（不追求工程复杂度）**
- Python 3.11、`openai` SDK（兼容 DeepSeek / 通义 / 智谱）、`pymupdf`（PDF 解析）、`numpy`（手写检索）、`chromadb` 或 `faiss`（后期替换）、`rank_bm25`（混合检索）、`fastapi` + `uvicorn` + `docker`（部署）

   ```python
   import urllib.request
   import xml.etree.ElementTree as ET

   NS = {"a": "http://www.w3.org/2005/Atom"}

   def search_arxiv(query: str, max_results: int = 10) -> list[dict]:
       url = (
           "http://export.arxiv.org/api/query"
           f"?search_query=all:{urllib.parse.quote(query)}"
           f"&start=0&max_results={max_results}"
       )
       with urllib.request.urlopen(url) as resp:
           raw = resp.read().decode("utf-8")
       root = ET.fromstring(raw)
       papers = []
       for entry in root.findall("a:entry", NS):
           papers.append({
               "title": entry.find("a:title", NS).text.strip(),
               "summary": entry.find("a:summary", NS).text.strip(),
               "id": entry.find("a:id", NS).text.strip(),
           })
       return papers
   ```

### W2 · 调用大模型、流式输出、记录失败案例

#### Day 1（周一 11/30）接入 API
`.env`：
```
LLM_API_KEY=sk-xxx
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
```
`llm.py`：
```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("LLM_API_KEY"),
    base_url=os.getenv("LLM_BASE_URL"),
)

def chat(messages, temperature=0.0):
    resp = client.chat.completions.create(
        model=os.getenv("LLM_MODEL"),
        messages=messages,
        temperature=temperature,
    )
    return resp.choices[0].message.content, resp.usage
```
> 国内多数平台兼容 OpenAI SDK，改 `base_url` 即可。**`temperature=0` 做评测必须用，记住这一点。**

## 7. 硬规则（W1 起适用，恢复期不适用）

1. **每天必须有 commit。** 没有 commit 的一天算没学，哪怕只改了一行 README。
2. **不追求"学完"。** 遇到不懂的，先让程序跑通，再回头看原理；教程看 30 分钟必须动手。
3. **主线项目只有 1 个。** 这 8 周不碰第二个方向（不碰 CV、不纠结微调框架、不换第二个 Agent 框架）。
4. **计划要给中断留位置。** 这次的教训不是"要更自律"，而是原表按 56 天连续可用排日期，一次手术就让后面每一格失灵。以后任何一周没跟上，**默认动作是整体往后平移，不是压缩内容去追日期**——压缩只会让下一周更难。
